Bienvenue dans Guymacyb243

Guymacyb243 est une application Windows de cybersécurité qui exécute de vrais outils Linux (nmap, nikto, sqlmap, aircrack-ng…) via WSL 2, pilote de vrais environnements Docker isolés, et intègre de vrais terminaux natifs (PowerShell, CMD, bash WSL).

WSL 2 — pour exécuter les outils Kali Linux (nmap, nikto, aircrack-ng…)
Docker Desktop — pour le Laboratoire (DVWA, Juice Shop, Metasploitable…)
Outils Linux (apt-get install nmap, sqlmap, hashcat…)
Terminaux natifs (node-pty — exécution réelle, pas de simulation)
⚠ Cet assistant vérifie réellement chaque composant et n'autorise pas une configuration incomplète. WSL et Docker nécessitent une élévation administrateur (UAC). L'installation des outils Linux se fait dans WSL via apt.
